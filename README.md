## 專案概述

數數計時器是一套專為運動、復健、冥想或固定間隔計數設計的高精準計時網頁應用。核心特色為每 10 秒進行動態語音報數（第 10s 報「1」、第 30s 報「2」、第 50s 報「3」...），並於每 20 秒交替播放清脆提示音，免除運動過程中需隨時低頭看螢幕的困擾。

---

## 核心功能與升級特色

1. **預設熱身準備階段 (Warm-up 10秒)**：
   - 點擊開始後預設啟動 10 秒熱身倒數，以暖色環形進度條提示預備時間。
   - 於最後 3 秒（3、2、1）自動進行語音倒數播報，並於倒數歸零時發出高音量提示音與「開始」語音，順暢銜接正式計時。

2. **核心報數邏輯**：
   - 每 10 秒判定一次週期。
   - 奇數十秒（10s, 30s, 50s...）：語音朗讀累計報數（1, 2, 3...）。
   - 偶數十秒（20s, 40s, 60s...）：合成清脆雙音階提示音（音量達滿載輸出，清脆響亮）。
   - 每秒可選木魚敲擊聲（音量再放大 100%，空靈清晰，一鍵開關）。
   - 完成時播放和弦收尾音。

3. **高精準背景計時核心**：
   - 內建 Web Worker 獨立線程計時，防止行動裝置瀏覽器因切換分頁或進入待機而發生計時延遲與節流問題。

4. **防休眠螢幕常亮 (Screen Wake Lock)**：
   - 啟動計時自動鎖定螢幕常亮，防止訓練期間手機自動鎖定黑屏；暫停或重置時自動釋放喚醒鎖。

5. **現代化視覺設計與大字體互動**：
   - 沉浸式暗色模式與動態 SVG 環形進度指示。
   - 全介面文字放大兩級字號，易讀性大幅提升。
   - 當前報數與即時狀態整合於同一橫幅指示卡，佈局精簡直覺。
   - 支援暫停、繼續、重置完整控制流程與觸覺震動回饋。

5. **PWA 離線應用支援**：
   - 具備完整 `manifest.json` 與 `sw.js` (Service Worker)。
   - 支援 iOS Safari「加入主畫面」與 Android 獨立 App 模式安裝，無網路亦可離線運行。

6. **GitHub Pages 即開即用**：
   - 根目錄包含標準 `index.html`，啟用 GitHub Pages 即可直接部署上線。
